ตรวจว่า ค่าขนส่งที่ Flash / ไปรษณีย์เรียกเก็บ ตรงกับ เรทที่ควรเป็น หรือไม่ โดยเทียบ 2 เรื่องแยกกัน:

① เรทถูกไหม — ขนส่งคิดเงินตรงตามตารางเรท (ตามน้ำหนักที่ตัวเองชั่ง) หรือเปล่า → เจอ "เก็บเกิน/เก็บขาด" 🟥🟧
② น้ำหนักตรงไหม — น้ำหนักที่ขนส่งชั่ง ตรงกับที่เราบันทึกใน JST ไหม ถ้าขนส่งชั่งหนักกว่า อาจทำให้ข้ามขั้นเรท = จ่ายเกิน 🟦

ทั้งหมดทำในเครื่อง (ในเบราว์เซอร์) ข้อมูลไม่ถูกส่งออกไปไหน

ขั้นตอนใช้งาน (ทีละสเต็ป)

  1. เปิดแท็บ "📊 ตรวจสอบชุด"
  2. อัปไฟล์ฝั่งเรา (JST export) ในกล่องซ้าย — ไฟล์ที่มีคอลัมน์ บริษัทขนส่ง / หมายเลขพัสดุ / น้ำหนัก / COD
  3. อัปไฟล์บิลขนส่ง ในกล่องขวา (ทีละเจ้า) — บิล Flash หรือ บิลไปรษณีย์ อย่างใดอย่างหนึ่งต่อ 1 รอบ
  4. ตรวจการจับคู่คอลัมน์ (ขั้นที่ 2) — ระบบเดาให้อัตโนมัติ แต่ควรไล่ดู dropdown ให้ตรงคอลัมน์จริง โดยเฉพาะ "หมายเลขพัสดุ" (ใช้จับคู่ 2 ไฟล์) และ "ยอดเก็บจริง"
  5. กดปุ่ม "▶ ตรวจสอบ" → รอ spinner สักครู่ → ผลจะแสดงด้านล่าง
  6. ดูแถบเตือนแดงด้านบน ถ้ามีรายการผิดปกติ แตะปุ่มในแถบเพื่อกระโดดไปดูเฉพาะกลุ่มนั้น
  7. กด "⬇ Export Excel" เพื่อบันทึกผลไปทำเรื่องเคลม/ตรวจต่อ
สำคัญ: ไฟล์ JST มีทั้ง Flash และไปรษณีย์รวมกัน แต่บิลแยกกันคนละไฟล์ → ต้อง รันทีละบิล (รอบแรกอัป JST + บิล Flash / รอบสองอัป JST + บิลไปรษณีย์) รายการของขนส่งอีกเจ้าที่ยังไม่ได้อัปบิลจะขึ้น "ยังไม่มีบิล"

สูตรการคิดเรท (ระบบคำนวณยังไง)

ระบบคำนวณ "เรท" จากตารางเรท (แท็บ 📋) + น้ำหนัก โดยแยกเป็น 2 ค่า ต่างกันแค่ใช้น้ำหนักคนละตัว:

เรทของเรา = คิดจาก นน.เรา (ที่บันทึกใน JST) · เรทควรเป็น = คิดจาก นน.ขนส่ง (ที่ขนส่งชั่งจริง) — สูตรเดียวกัน ต่างที่น้ำหนัก

🟡 Flash

  1. น้ำหนักคิดค่า = น้ำหนักจริง (ถ้าเปิด "คิดปริมาตร" = ตัวที่มากกว่าระหว่าง น้ำหนักจริง กับ ปริมาตร÷ตัวหาร)
  2. เปิดตารางเรท Flash ตามน้ำหนักคิดค่า → ได้ เรทฐาน (BKK/UPC ตามจังหวัดปลายทาง)
  3. + ค่าธรรมเนียม COD 1% ของยอด COD
  4. รวม = เรทฐาน + (COD × 1%) ← ตรงกับยอด Total ในบิล Flash
  5. กรณี >50kg: ทุก 5cm=1kg → ×15฿ (BKK) / ×10฿ (UPC)
ตัวอย่าง: น้ำหนัก 2.74kg, COD 2,190฿ → เรทฐาน (≤3.5kg) = 12฿ + COD (2,190×1%) = 21.9฿ → รวม 33.9฿

🔴 ไปรษณีย์ไทย

  1. เปิดตารางเรทไปรษณีย์ตามน้ำหนัก → เรทฐาน (≤1kg=20 · ≤2kg=30 · เพิ่มขั้นละ 10฿ ถึง 110 แล้วขั้นละ 5฿ ถึง 160)
  2. + 2฿/ชิ้น (ค่าบริการเพิ่ม สัญญาข้อ 7)
  3. + 20฿ ถ้าปลายทางพื้นที่พิเศษ
  4. ค่าบริการ = เรทฐาน + 2 (+20 ถ้าพื้นที่พิเศษ)
  5. COD ของไปรษณีย์คิดแยกรอบ (ไม่รวมในค่าบริการ) · >20kg: ฐาน 160 + 15฿ ต่อ kg ที่เกิน 20
ตัวอย่าง: น้ำหนัก 0.4kg → เรทฐาน (≤1kg) = 20฿ + 2฿ = รวม 22฿

ดูช่อง "ต่าง(เรท)" เป็นตัวหลัก ว่าขนส่งคิดเรทผิด/เก็บเกินไหม:

0 (หรือใกล้ 0)✅ คิดเรทถูก ไม่โกงไม่ต้องทำอะไร

แก้ตารางเรท

  1. ไปแท็บ "📋 ตารางเรท"
  2. แตะปุ่ม ✏️ ท้ายแถวที่ต้องการแก้ → เด้งป๊อปอัพ
  3. แก้ตัวเลข แล้วกด "✔ ยืนยัน" (กด "ยกเลิก" = ไม่บันทึก)
  4. Flash เพิ่ม/ลบแถวได้ (ปุ่ม + เพิ่มแถว / 🗑 ในป๊อปอัพ) · แถว ">20kg" ของไปรษณีย์คือฐานเริ่ม + บวกต่อ kg
  5. ปุ่ม "รีเซ็ตค่าเริ่มต้น" คืนค่าเดิมทั้งตาราง (มีถามยืนยัน)
